## 同轮第二刀：撤除"帮 JEI 办事"的整层（含登记表与文案层）

用户裁定原话：**「这当然也是被勿增的实体，jei 在缺料的时候可不会弹出来一条文字让你阅读，而是直接标红缺少的材料。我的意思是，我们就不该有这一层"帮 jei 把事办了"的层」**。判据落地：JEI **自己**把缺的材料标红、**自己**决定「+」能不能点；我们**不该**在旁边替它裁决，更不该替它写作文。本模组定位收缩为：**我们有我们自己的取料入口（面板 ＋ 原版配方书），JEI 保持原样**。

**这一刀删掉的**：
- **删文件**：`compat/jei/FmpRecipeTransfer.java`、`compat/jei/PreviewPolicy.java`、`client/ClientNotice.java`、`client/NoticeText.java`；对应单测 `PreviewPolicyTest.java`／`ProvablyUnsolvableTest.java`／`ClientNoticeTest.java`。
- **`FmpJeiPlugin`**：删 `registerRecipeTransferHandlers(...)` 整个方法、`craftingHandler` 字段与 `craftingHandler()` 访问器、以及那行 "FMP JEI transfer handlers registered" 日志。**保留** `onRuntimeAvailable/onRuntimeUnavailable`（我们面板的会话与排版）、`registerVanillaCategoryExtensions`（让 JEI **显示**我们的坠子锻造配方，显示≠代办）、`registerGuiHandlers`（我们面板的排除区）。
- **`LogisticsPanel`**：删 `fillRecipeForViewer`／`speakViewerResult`／`speakViewerTimeout` 与 `viewerWaiting`／`viewerMissing`；`tick()` 的超时**回到原本那一行** `notice("timeout")`；**`fillRecipe` 与 `notice` 原样保留**（面板补料与面板提示是我们**自己的门**）。
- **`ClientCrafting`**：为那一层长出来的 `Estimate`／`estimate(...)`／`shortfall(...)` **收回**成单一 `check(...)`，语义与判定顺序**逐字不变**（仍先 `MISSING` 后 `NO_SPACE`）；唯一调用者仍是原版配方书的 `RecipeCollectionHintsMixin`。
- **lang**：删只服务那一层的 3 个键（`result.missing_entry`／`result.missing_detail`／`result.missing_scope`，中英各一份；删后两份 JSON 仍可解析、无 BOM）；**`result.*` 其余键保留**（面板 `notice("result." + …)` 仍在用）。
- **`JeiClientReview`**（客户端复核用例）：原来断言"JEI 返回的处理器必须是我们的"，现在改成断言**不得出现属于本模组的转移处理器**。

**代价（写清楚）**：这一层删掉后，**任何整合包里本模组都不再让 JEI 的「+」吃缓存**——JEI 的「+」由 JEI 自己（或该注册位上的第三方）回答；缓存取料走**我们自己的物流面板**与**原版配方书**。

**仍然保留（判据一：功能不许被剃掉）**：① **物流面板**（缓存取料＋面板补料）；② **原版配方书**（`RecipeCollectionHintsMixin`／`RecipeBookHintsMixin`／`RecipeBookPlacementMixin`＋服务端 `CraftingService.fromRecipeBook`：配方书显示"可合成"且点击**真能从缓存取料**，显示与能力一致）；③ `MaterialHints`／`ClientMaterials`（缓存视图）；④ JEI 插件里"面板会话／排除区／锻造配方显示"三件。

**守卫**：单测 `JeiIntegrationIsApiOnlyTest`（5 例）扩到断言这一层不得回来——jar/类路径里不得有那四个类，`FmpJeiPlugin` 的字节码里不得出现 `registerRecipeTransferHandlers`／`craftingHandler`／`mezz/jei/api/recipe/transfer`，两个 lang 文件不得再有那三个键，同时断言"面板会话（`recipeOverlay`）／锻造显示／排除区"仍在。
