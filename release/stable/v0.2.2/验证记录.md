## 三、核实队长的判断：配方页打开时面板确实不渲染

**成立，且证据在源码里**（`client/LogisticsPanel.java`）：面板只在**它自己的容器界面**上渲染——`current(candidate)`＝`candidate == screen && supported(candidate) && window != null`（`:331-333`）；渲染入口 `ScreenEvent.Render.Pre`（`:166`）／`foreground(...)`（`:585`）／`postRender(...)`（`:599`）**都先过 `current(...)`**；那条 notice（`feedback`）只在 `render(g)` 内被画（`:653-657`）。JEI 的配方页是 `runtime.getRecipesGui()`（`FmpJeiPlugin.java:32` 把谓词设成它），`tick()` 里的 overlay 分支（`:359`）**只保持会话不被关闭**、并不渲染。⇒ 配方页盖住时**那句话玩家看不到**。
关键补充：`receive(...)`（`:474`）在 overlay 打开时**仍然处理快照** ⇒ 服务端的裁定**确实到达了客户端**，只是过去没有任何玩家可见的位置显示它——这正是"静默失败"的机理，也是本轮改用动作栏的原因。
