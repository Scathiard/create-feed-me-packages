# Create: Feed Me Packages! 0.2.2（正式包目录）

- 本目录是 **0.2.2 正式包**的记录与产物（jar 与源码快照按惯例不入库）。
- **红线（用户 2026-09-17 裁定）**：**不得劫持 JEI 的「+」**。本包**不使用任何针对 JEI 的 mixin／反射**，也不替换、否决任何第三方已注册的处理器；JEI 接入**只走官方 API**。0.2.2 曾有一版采用"接管"方案（拦截 JEI 取处理器的入口并替换原处理器），**已被用户禁止、本包已全部撤除**（详见 `变更说明.md`「重大更正」一节）。
- 产物（本目录）：
  - `create-feed-me-packages-0.2.2.jar`＝**392,970 B**／`335f0efb98906a0723ccf4a16b1a77d4fe9198aeaaa602722b0291a1c803fdb6`
  - `v0.2.2-source.zip`＝**681,447 B**／`32718ccf1a5b2b94221e2f6c6ea33ab9596b5db088fb2b5b4db824e67f98cb9d`（源码快照＝分支 `release/0.2.2` @ `8965070`，即产出该 jar 的源码提交）
  - 校验以 `SHA256SUMS.txt`／`SOURCE_SHA256SUMS.txt` 为准；**历史轮次（含被撤除的接管版）的 hash 只在 `验证记录.md` 里作记号**。
- **已知问题**：装了「机械动力：存储」（Create: Storage，`fxntstorage`）时，工作台配方的「+」由**该模组**回答（它只认身上背的背包）⇒ **缓存补料不走「+」**；请用**物流面板**或**原版配方书**。与本模组无关，也不只影响本模组（措辞与 `v0.2.1` 的已知问题一致）。
- 编译基线：Minecraft 1.21.1／NeoForge 21.1.219（>=）／Create 6.0.10／Curios 9.5.1；**JEI 为可选依赖**（未安装时 JEI 相关类整体不加载）。
- 安装：把 jar 放进 mods\；回退＝删除该 jar 或换回 0.2.1。
- 详情见同目录：`变更说明.md`／`验证记录.md`／`测试清单.md`／`依赖说明.md`；发布正文＝`gh-notes.md`（中文）／`gh-notes.en.md`（英文）。
- **同轮第二刀（同日）**：**撤除「帮 JEI 办事」的整层**——本模组**不再注册任何 JEI 配方转移处理器**，也没有预览政策与动作栏文案层（`FmpRecipeTransfer`／`PreviewPolicy`／`ClientNotice`／`NoticeText` 及 3 个只服务它的 lang 键已删）。**代价**：任何整合包里本模组都不再让 JEI 的「+」吃缓存；缓存取料走**物流面板**与**原版配方书**（两者能力不变）。守卫单测 `JeiIntegrationIsApiOnlyTest` 已扩到断言这一层不得回来。
- **同轮第三件（兼容注入）**：与 Create: Storage（`fxntstorage`）兼容——在**他们自己的** JEI 客户端预览与**他们自己的**服务端传输路径上做两个**软定点注入**（`fmp_fxntstorage_compat.mixins.json`，`required:false`＋`defaultRequire:0`，三个 `@Pseudo` mixin），把**我们的缓存**当成他们的**第三个货源**：他们的空物品槽现出一份缓存副本、他们写回时精确扣我们的缓存、**绝不写他们的容器**；**判定/摆料/显示仍是他们的**，我们不注册 JEI 处理器。**没装他们时零影响**，他们改内部即**安静退化**。细节与脆弱性见 `变更说明.md` 末尾一节。
