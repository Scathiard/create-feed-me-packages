# 依赖说明（0.2.2）

| 依赖 | 版本 | 必需性 | 说明 |
| --- | --- | --- | --- |
| Minecraft | 1.21.1 | 必需 |  |
| NeoForge | 21.1.219 及以上 | 必需 |  |
| Create | [6.0.10, 6.1.0) | 必需 | 配方与物流面板的基础 |

| 其它（如 FXNT Storage/Create: Storage） | — | 可选 | 与本模组**注册在同一个 JEI 转移处理器键**上（JEI 该位置只允许一个、后注册者胜）。**本模组不接管、不替换**任何他人处理器：装了这类模组时该位置的「+」**由对方回答**，缓存补料请用**物流面板**或**原版配方书**（见 `变更说明.md`「已知问题」） |
