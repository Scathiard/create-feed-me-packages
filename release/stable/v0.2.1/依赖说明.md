# 依赖说明（0.2.1）

## 必需

| 依赖 | 版本 | 出处 |
| --- | --- | --- |
| NeoForge | `[21.1.219,)` | 包内 `META-INF/neoforge.mods.toml` 声明的 `versionRange` |
| Minecraft | `1.21.1` | 同上 |
| Create | `[6.0.10,6.1.0)` | 同上 |
| Curios API | `[9.5.1,10.0.0)` | 同上 |

> 四条范围**直接取自本 jar 内的 `neoforge.mods.toml`**（不是"应该如此"）。

## 可选

| 模组 | 说明 |
| --- | --- |
| **JEI**（Just Enough Items） | 可选。本模组的 JEI 适配是 `compileOnly` 编译、运行时"装了才发现"（`@JeiPlugin`），不装不会类加载报错。**注意已知限度**：重度整合包里 JEI「+」可能对工作台配方一直是灰的（见《变更说明.md》）。 |
| Create: Mobile Packages 等运输模组 | 可选，用于退货／补货的真实运输；0.2.1 未改运输路径。 |

## 不随包提供

不打包任何依赖（无 JarJar 内嵌），不附带配置文件（首次启动按默认生成）。
