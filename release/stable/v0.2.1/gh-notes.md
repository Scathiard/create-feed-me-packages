# 0.2.1

- **不再重复续填合成格**：以前取一次成品会从缓存取料并暗中填回合成格，一次 Shift 点击可能消耗远超网格真实材料的量。现在取成品**回到原版行为**：只按网格里真实存在的材料结算一次。

## 已知问题

- **装了「机械动力：存储」（Create: Storage，`fxntstorage`）时**，JEI 取料合成时点击「+」不会使用缓存里的物品。原因已查清：该模组会**无条件抢占**"工作台配方转移"这一个注册位（JEI 同一位置只允许一个处理器、后注册者胜），而它只认身上背的背包，于是工作台配方的「+」呈**灰**并给出**原版「缺少物品」**提示。**与本模组无关，也不只影响本模组**——任何在它之前注册该位置的模组都会被顶掉。**替代做法**：**物流面板**与原版**配方书**取物照常可用（材料在缓存里同样能供料）。
