# 机械动力：喂我发包！


[![CurseForge](https://img.shields.io/badge/CurseForge-%E4%B8%8B%E8%BD%BD-F16436?logo=curseforge&logoColor=white)](https://www.curseforge.com/minecraft/mc-mods/create-feed-me-packages) [![Modrinth](https://img.shields.io/badge/Modrinth-%E4%B8%8B%E8%BD%BD-00AF5C?logo=modrinth&logoColor=white)](https://modrinth.com/mod/create-feed-me-packages)

下载：[GitHub Releases](https://github.com/Scathiard/create-feed-me-packages/releases)

## 项目介绍

工厂已经能自动生产建材了，出门盖房子却还得一趟趟回去搬。**机械动力：喂我发包！** 帮你省掉这段路！

戴上供应链坠，连好工厂的物流网络，告诉它你想常备哪些物资。用掉一部分，坠子就向工厂请求补货。打包机装箱，运输员送来，包裹里的材料自动收进背包左侧的随身缓存。临时要合成东西，也能直接从里面取料。
你将会需要额外安装有远程配送能力的模组，否则你就只能请你的朋友来当快递员了。

这套玩法借鉴了《戴森球计划》的运输机物流。放到 Minecraft 里，我们希望自动补给也能成为你那套机械动力工厂的一部分。模组适用于 **Minecraft 1.21.1 / NeoForge**，需要 **Create** 和 **Curios**。

## 使用场景

- 出门建造，把常用方块和机器列进补货清单，少跑几趟仓库。
- 扩建工厂，临时缺了合成材料，可以直接用缓存里的存货，不必用便携终端请求。
- 带上箭矢、食物等消耗品，让工厂自动补充缓存，把普通背包的位置留给路上捡到的东西。
- 和朋友一起玩，可以连同物资和补货设置把坠子交给对方。

## 功能能力

### 供应链坠

物资和设置跟着坠子走。交给朋友，对方就能接着用；坠子毁坏，也就失去了这份库存。

每人最多戴一件。摘下后，存取、补货、收件和自动取料都会停下，库存与设置留着，重新戴上再用。

### 独立缓存与自动补货

戴上坠子，背包左侧就会多出缓存格，把物品放进空格，或者在 JEI／EMI 列表里对着物品或流体按快捷键（默认鼠标中键），就定下了这一格要存什么；点格子角落的小点，设置希望常备多少。

如果你想常备两组原木，就把补货下限设为两组。缓存低于这个数量时，坠子会向网络请求差额。它只看缓存里的存货，不把普通背包里的物品算进去。

角点打开的**格控面板**可以集中调整补货下限、退货上限、单次最少补货量与单次最少退货量。支持滑条拖动（在整组倍数处吸附）与滚轮调数（普通滚轮 ±1，按住 Shift ±1 组）。如果设置单次最少补货量为 64 件，即使只缺 1 件也会请求至少 64 件，网络库存不足就等。中央包裹显示已请求但尚未结清的数量，点击重置在途包裹；不会自动过期清账。

补货请求默认使用 `@玩家名` 地址。寄给玩家的包裹只要所有内容物都匹配已有的缓存过滤，且对应缓存格未满、未达退货上限，送达后就会直接拆进缓存，不用先往普通背包里倒一遍；手动寄出的同类包裹同样适用。暂时装不下的材料会留在包裹里，等腾出位置再继续收。

能存入的物品会保留附魔等数据，同名但数据不同的物品分格存放。无法安全保存的物品会被拒绝，不会偷偷变成普通版本。面板上的「一键收取」可以把背包里匹配已有过滤的物品直接收入缓存，未绑定物流网络时也能用；收起面板只隐藏界面，不会暂停后台物流。

### 自动退货

建完房子，多拿出来的材料还可以放回缓存。设置想留下的最高数量、单次最少退货量和返回地址，超出的部分达到条件后就会打成包裹，交给纸飞机、运输蜂、运输幻翼或悦灵快递员送回去。

退货需要相应的快递载具。没有合适的载具，或运输无法出发时，材料会留在缓存里，不会出发。

### 拣货夹与流体缓存

手持**拣货夹（Pocket Pallet）**可以直接调用缓存里的物资，无需先取回背包。按住快捷键（默认鼠标中键）打开圆弧或网格菜单（支持搜索与视图切换），松开确认选择后，右键即可放置方块、进食、饮用药水，或直接倒出缓存中的流体。

缓存格也能直接存放流体（每组容量为 8 桶）。支持手持空桶、玻璃瓶等流体容器在面板中直接存取流体，容器规则与对应流体本身一致；配合 Create: Fluid Logistics，还可以接收流体包裹入库，并按设定数量自动请求流体补货或打包退回多余流体。

### 车万女仆随身物流

车万女仆（Touhou Little Maid）佩戴供应链坠后，同样能自动请求补货、退回多余物资，并在进食或战斗时直接取用缓存中的食物、箭矢与枪械弹药。

可在女仆界面左侧直接管理她的缓存与物流设置。开启「自动入库」后，女仆新拾取且匹配已有过滤的物品会自动存入缓存，超出退货上限的部分也会自动打包退货。

### 容量成长

扩容也要用上工厂。通过 Create 序列组装做出扩容链节，再到锻造台升级坠子，就能装下更多种类、更多数量的物资。

| 等级 | 缓存格数 | 单格容量 |
| --- | --- | --- |
| 1 | 9 | 2 组 |
| 2 | 16 | 4 组 |
| 3 | 24 | 8 组 |
| 4 | 30 | 16 组 |
| 5 | 36 | 32 组 |

这里的一组按物品原本的堆叠上限算（流体按每组 8 桶计算）。一级的一个格子，可以放 128 个原木、32 颗末影珍珠、2 桶牛奶，或者 16 桶纯流体。

可在存档 `serverconfig` 中配置 1～5 级坠子的格数、单格组数上限、各模组联动开关及物品/流体存入黑白名单。调低容量配置后，超出新上限的原有库存保留为只读状态，仍可正常取出。

### 合成、弹药与建造取用

合成缺料时，不必把缓存翻一遍。原版背包的 2×2 合成、工作台的 3×3 合成、配方书、JEI／EMI 配方填充，以及精妙背包、精妙存储的合成升级和 Create: Storage 背包合成，都能在背包原料不足时从缓存补齐。面板底部提供**合成取用开关**，可按坠子单独开启或关闭缓存参与合成。

原版弓/弩、TaCZ（官方版与非官方移植版）和卓越前线（含手持枪械与玩家实际操作的载具武器）支持在背包缺弹时接着用缓存里的弹药；建筑魔杖、建造小帮手 2 和简易建造也支持直接从缓存消耗建造方块。取料顺序固定为背包优先，缺多少再从缓存拿多少。

## 模组联动

| 模组 | 是否必需 | 联动内容 |
| --- | --- | --- |
| **Create／机械动力** | 必需 | 工厂供货。坠子绑定物流网络、查询库存并请求补货，由打包机把材料装成包裹；扩容链节也通过序列组装制造。 |
| **Curios API** | 必需 | 提供供应链坠的佩戴槽位。 |
| **Create More: Package Couriers（纸飞机）** | 可选 | 用纸飞机向玩家与女仆配送补货包裹，以及将退货包裹送回仓库。 |
| **Create: Mobile Packages（运输蜂）** | 可选 | 用运输蜂向玩家与女仆配送补货包裹，以及将退货包裹送回仓库。 |
| **Create: Phantom（机械动力：幻翼物流）** | 可选 | 用幻翼快递员向玩家与女仆配送补货包裹，以及将退货包裹送回仓库。 |
| **Create: Biotech（机械动力：生物科技）** | 可选 | 用悦灵快递员向玩家与女仆配送补货包裹，以及将退货包裹送回仓库。 |
| **Create: Fluid Logistics（机械动力：流体物流）** | 可选 | 接收流体包裹入库，并按设定数量自动请求流体补货或打包退回多余流体。 |

| **EMI** | 可选 | 配方填充时从缓存补齐缺失材料，通过快捷键（默认中键）从列表选取物品或流体设置缓存过滤。 |

| **Sophisticated Storage（精妙存储）** | 可选 | 存储容器内的合成升级在缺料时从缓存补齐材料。 |
| **Create: Storage（机械动力：存储）** | 可选 | 佩戴背包时，合成取料与 JEI／EMI 配方填充可同时访问背包与缓存库存。 |
| **Crafting Tweaks** | 可选 | 兼容工作台旋转、平衡与清空操作。 |
| **TaCZ（永恒枪械工坊）** | 可选 | 同时支持 1.21.1 官方版与非官方移植版在背包缺弹时从缓存取用弹药（含逐发装填枪械）。 |
| **Superb Warfare（卓越前线）** | 可选 | 手持枪械与玩家实际操作的载具武器在背包缺弹时从缓存取用弹药。 |
| **Construction Wand（建筑魔杖）** | 可选 | 建造时直接从缓存消耗方块。 |
| **Building Gadgets 2（建造小帮手 2）** | 可选 | 建造时直接从缓存消耗方块。 |
| **Effortless Building（简易建造）** | 可选 | 建造时直接从缓存消耗方块。 |

工厂里得有货，包裹也得有办法送到你手里。纸飞机、运输蜂、幻翼和悦灵需要各自的设施、地址与配送条件，坠子不会替你搭好这些，也不会隔空从仓库取走材料。不装这些可选模组，仍能使用缓存和基础功能，通过其他方式取得符合收件规则的包裹后也能收件。或许，你们可以考虑当个快递员？
